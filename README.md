# 🌸 Project Re:YUA

Flaskで制作したAIチャットアプリです。

## 概要

ユーザーとの会話を記憶し、プロフィールや好感度などを管理できる
キャラクターAIを目指して制作しています。

## 主な機能

- 名前の記憶・呼び出し
- 好きな食べ物の記憶
- 目標の記憶
- 思い出の記憶
- 好感度システム
- プロフィール表示
- チャット履歴
- 履歴削除
- Webブラウザ上での操作

```bash
python app.py
```

ブラウザで以下を開きます。

http://127.0.0.1:5000
