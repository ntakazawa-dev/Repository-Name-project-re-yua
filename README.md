# 🌸 Project Re:YUA

## 概要

Project Re:YUA は、ユーザーとの会話を記憶し、次回起動時にも思い出せる「共に成長する相棒」をコンセプトに開発した Python 製の対話アプリです。

ユーザーの名前、好きな食べ物、思い出、目標を JSON ファイルへ保存し、アプリを再起動しても記憶を保持できます。

現在は Tkinter を使用した GUI 版を実装しており、入力欄・送信ボタン・チャットログを通して、チャットアプリのように操作できます。

## 主な機能

### 名前の記憶

* ユーザー名を登録
* 登録した名前を後から確認可能

### 好きな食べ物の記憶

* 好きな食べ物を登録
* 登録した好きな食べ物を後から確認可能

### 思い出の保存

* 日々の出来事を記録
* 登録した思い出を一覧表示

### 目標の保存

* ユーザーの目標を記録
* 登録した目標を後から確認可能

### データ永続化

* JSON形式で保存
* 再起動後も記憶を保持

### GUI操作

* Tkinterによる画面表示
* 入力欄、送信ボタン、チャットログを実装
* Enterキーによる送信に対応
* チャットログの自動スクロールに対応
* 背景色やボタンなど、簡単なUI調整を実装

## 工夫した点

* `gui.py`、`main.py`、`memory.py` に役割を分け、画面処理・会話処理・データ管理の責務を分離しました。
* 記憶データを「名前」「好きな食べ物」「思い出」「目標」に分類し、機能追加しやすい JSON 構造を意識して設計しました。
* データを JSON ファイルへ保存することで、アプリ再起動後もユーザー情報を保持できるようにしました。
* `entry.bind("<Return>", send_message)` を使用し、送信ボタンだけでなく Enter キーでもメッセージを送信できるようにしました。
* `chat_log.see(tk.END)` を使用し、会話が追加された時に自動で最新メッセージまでスクロールするようにしました。
* コメントを追加し、名前・好きな食べ物・目標・思い出など、処理ごとにコードを整理しました。

Python学習のアウトプットとして開発しました。
